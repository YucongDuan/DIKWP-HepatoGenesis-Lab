Run an experiment

Python 3.10 or newer. Standard library only. Download and extract the source, then run:

python -m hepatogenesis doctor
python -m hepatogenesis demo --out runs/first-experiment
python -m hepatogenesis verify runs/first-experiment
python -m hepatogenesis serve --port 8766

Open http://127.0.0.1:8766 for live calculations. Read the full quick start.
